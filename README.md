# abafaboy.github.io

Portfolio site for Abafa Mukhamedov (abafaboy). One static page, no build step: push to a repo named `abafaboy.github.io` and GitHub Pages serves it at https://abafaboy.github.io.

The manhwa readers include an optional shared-engagement frontend and a public
[owner overview](manhwa/owner.html). The service is disabled until a backend is
approved and configured; unavailable counts are never substituted with local
reading progress. See [the integration contract and setup plan](docs/engagement.md).
