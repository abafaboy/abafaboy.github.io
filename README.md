# My Summons Go First: remake bible (branch `msgf-bible`)

- `STORY_BIBLE.md`: the series: themes, real-world issues, world rules, cast, motifs, foreshadowing ledger.
- `PART_ONE_BEATS.md`: chapter-by-chapter beats for chapters 1–100.
- `ART_BIBLE.md`: drawing, lettering and UI rules (from a survey of 103 real webtoons).
- `SCRIPT_FORMAT.md`: the YAML format for chapter scripts.
- `scripts/chNNN.yaml`: chapter scripts.
- `codex/`: task briefs given to Codex sessions.
- `research/`: the visual survey, and the digest of the published chapters 1–7.
- `ledger/PLANTED.md`: where each foreshadowing plant actually landed.

Built on Abafadot's architecture v3 (branch `msgf-source`). Contains major spoilers.
