# NAME SHEET: fixed spellings for *My Summons Go First* (rebuild, v4)

**What this is.** Every name, place, group and term in `STORY_BIBLE_v4.md`, spelled one way.
- Scripts, captions, windows, narration and file names use exactly these spellings.
- Korean names are family name first (Kang Jaeha), with no hyphen inside the given name.
- File and folder ids use lower-case snake_case (`kang_jaeha`, `song_yerin`).

**The "say it" column.** A rough English respelling for the narrator, so the voice reads names the same way every time. It is approximate, not a Korean pronunciation guide.
