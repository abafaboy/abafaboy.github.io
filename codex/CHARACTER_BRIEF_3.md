# CHARACTER BRIEF 3: the later Part One cast and key props (method B)

Same method and rules as `CHARACTER_BRIEF_2.md`. Read the same files first, and match the style, line weight and colour treatment of `characters/taeo/` and `characters/nib/`. Run the ART_BIBLE Part C anti-AI checklist on every sheet. No text in any image. Write only inside your characters' own folders, `props/` and `characters/REPORT_SET3.md`. Do not touch any other folder; other Codex chats are drawing chapters at the same time.

## Deliverables per character
In `characters/<id>/`:
- `turnaround.png` (1536×1024): front, three-quarter, side and back, full body, neutral pose, plain light-grey background.
- `expressions.png` (1536×1024): 8 head shots (neutral, smile, anger, fear, grief, surprise, determined, their signature expression).
- `details.png` (1536×1024): props, hands, locked details, close-ups.
- `card.json`: id, name, age, height, palette hex values, and continuity locks as a list.

Characters marked **(minor)** need only `turnaround.png` and `card.json`.
