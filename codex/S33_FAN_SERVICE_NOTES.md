- **References.** Use only the approved sheets named below, at most four per image.

  - Change only what the entry says.
  - Pass no outside pictures and no old versions of the sheet being redone.
- **Format.** 1536×1024 PNG, plain light grey background, no text or labels. The STYLE BLOCK and CLEAN-UP LINE as in every prompt.
- **Hands.** Hands and arms come first (`PANEL_BRIEF_v2.md` 4c). Crop every hand at 2x and check it before you keep an image.
- **Tries.** Up to 3 per image.
  - Rejects go to `characters_v2/_rejects/S33_<name>_<try>_<reason>.png`.
  - Save every kept image as an ordinary file (no hard links).
